# Luqui & Lali · Nuestra plata

Versión preparada para uso compartido en dos celulares con Firebase Authentication y Cloud Firestore.

- `index.html`: interfaz y pantalla de inicio de sesión.
- `styles.css`: diseño responsive.
- `app.js`: movimientos, pagos, ahorros y sincronización en tiempo real.
- `firebase-config.js`: configuración específica del proyecto Firebase (completar antes de usar).
- `firestore.rules`: reglas de seguridad para autorizar únicamente los dos UID de la pareja.
- `manifest.json`, `sw.js`, `icon.svg`: instalación PWA.
- `LEEME.md`: guía paso a paso de configuración, publicación, pruebas y migración de datos.

**No usar con datos reales hasta completar la configuración Firebase y publicar las reglas privadas.** La sincronización no se activa con los valores de ejemplo.
